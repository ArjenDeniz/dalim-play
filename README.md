# Bu gece gösterimde

A vibe-coded experiment: a small surprise for Dalım's birthday, made for one night with one friend group.
Most of it was written by AI with only a light human touch, and the whole thing was built in three sessions.

Live at https://iyikidogdundalim.arjendeniz.com

- **Dalım’ın 2026’sı** — Dalım's year in film, as a scroll-through reel
- **Film Kapışması** — a live quiz, answered on phones
- **Emoji’den Filmi Bil** — guess the film from emojis

```sh
npm install
npm run dev
```
