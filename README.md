# Bu gece gösterimde

A vibe-coded experiment: a small surprise for Dalim's birthday, made for one night with one friend group.
Most of it was written by AI with only a light human touch, and the whole thing was built in three sessions.

Live at https://dalim-play.vercel.app

- **Dalim’in 2026’sı** — Dalim's year in film, as a scroll-through reel
- **Film Kapışması** — a live quiz, answered on phones
- **Emoji’den Filmi Bil** — guess the film from emojis

```sh
npm install
npm run dev
```
